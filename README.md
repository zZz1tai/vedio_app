# 夜映 YeYing

手机上的 AI 视频处理工具:视频变高清、图片变高清、视频补帧,全部在手机本地完成——**不联网、不注册、不上传**,你的照片和视频不会离开手机。

## 下载安装

1. 打开 [Releases 页面](https://github.com/zZz1tai/vedio_app/releases/latest)
2. 下载最新版的 APK 文件(文件名带 release 的那个)
3. 点开下载的 APK 安装。如果手机提示"禁止安装未知来源应用",按手机提示允许即可
4. 需要 Android 7.0 及以上,并支持 Vulkan(近几年的手机基本都满足)

## 能做什么

**图片变高清**
模糊的老照片、聊天截图、网上保存的压缩图,选 2 倍或 4 倍放大,AI 重建细节,处理完自动存进相册。

**视频变高清**
低清视频放大 2 倍分辨率,AI 逐帧重建,画面更细腻。

**视频补帧**
普通 30 帧的视频补成 60 帧,滚动、打斗、运动画面更流畅丝滑。

**看视频**
内置专业播放器(mpv 内核),支持 Anime4K 实时画质增强,还能从 B 站导入视频。

**管理图片和视频**
相册式网格浏览,双指捏合随时调整网格大小,可以扫描出手机里所有角落的图片。

## 怎么用(三步)

1. 打开 App,底部选「视频」或「图片」标签
2. 选中要处理的文件,选择 2x(快)或 4x(更清晰但更慢)
3. 等待处理完成,点预览图可以全屏查看、双指捏合放大对比原图,满意就保存

## 常见问题

**处理要多久?**
AI 是逐帧计算的,一分钟的视频可能要跑几十分钟,和手机性能有关。建议先用 10 秒短片试试效果。

**手机发热正常吗?**
正常。AI 计算量很大,发热说明 GPU 在全速工作,不会损坏手机。

**处理结果存在哪?**
图片在相册的「Pictures/夜映/AI」文件夹,文件名是「夜映AI超分_时间戳」;视频处理完按页面提示导出。

**需要联网吗?**
完全不需要。AI 模型内置在 App 里,断网也能用。

**为什么感觉效果不明显?**
处理完一定要点预览图进全屏,双指放大到 100% 再对比原图——缩在缩略图里看是看不出区别的。另外,原本就非常糊的图(强压缩、马赛克严重),AI 能修复的极限也有限,它擅长的是"清晰图变得更好",而不是"无中生有"。

## 技术原理

| 功能 | 技术 |
|---|---|
| 图片超分 | Real-ESRGAN x4v3(ncnn + Vulkan GPU 加速) |
| 视频超分 | Real-ESRGAN animevideov3 |
| 视频插帧 | RIFE v4.6 光流模型 |
| 播放器 | libmpv + Anime4K |
| 应用框架 | React Native (Expo) + Android 原生模块(C++ / Kotlin) |

所有 AI 推理都在手机本地 GPU(Vulkan)上运行,不依赖任何云服务。

## 给开发者

本仓库为 monorepo 结构:client(Expo 应用)+ server(Express 服务)。

```bash
cd client && npm install
cd android && ./gradlew assembleRelease
```

构建产物在 `client/android/app/build/outputs/apk/release/`。
